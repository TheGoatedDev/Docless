# Record architecture decisions

We keep short ADRs in `docs/adr/` as `NNNN-slug.md` so “why” survives refactors. Write one only when the choice is hard to reverse, surprising without context, and a real trade-off. Format: title + 1–3 sentences (optional status/options/consequences). Next number = max existing + 1. Prefer the `add-adr` skill when adding more.
